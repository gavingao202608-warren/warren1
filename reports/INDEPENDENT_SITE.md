# 独立产品交付

产品使用独立站点名 Warren Vehicle Finder。原官网只是只读资料来源；没有修改其页面、库存、设置、账号或服务器。原官网的数据并非我们拥有的库存，页面标注来源卖家，报价和在售状态须向原卖家核实。

咨询只保存到我们自己的 SQLite 数据库和认证后台，不自动发送给原官网或车商。联系授权明确指向独立站点运营者。后台可标记 contacted / qualified / closed / spam，也可删除咨询；测试咨询、无联系方式或未同意联系的咨询不能标记为 qualified。

提供邮件/手机号时校验格式；客户提交后得到咨询编号，隐私页说明独立运营、外部图片请求及删除申请办法。网站没有自动通知功能，运营者必须查看后台。

部署条件：Node 24、稳定 HTTPS 域名、持久化数据盘、私密 ADMIN_PASSWORD、实际 PUBLIC_BASE_URL 和 ACQUISITION_STARTED_AT。项目包含 Dockerfile 和 Compose。没有读取或使用原官网管理凭证。

免费 Render 官方资料明确说明本地 SQLite 在休眠/重启/部署时丢失，免费实例不能使用持久磁盘，因此仅用本地 SQLite 的版本不能直接作为 Render 免费实例交付；现已添加独立 PostgreSQL 客户存储适配，部署方案见 DEPLOY_FREE.md。GitHub 提供代码下载，不提供本项目所需的 Node/SQLite 后端。

当前无已绑定的独立托管账号及持久化数据库服务。代码和本机功能可完成验证；公网持续服务必须先取得可用的托管授权或用户持续开机的运行电脑。不能用源网站服务、伪造主机身份或冒用品牌来替代。
