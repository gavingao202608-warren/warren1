# 当前最短操作路线

产品已改为独立站 Warren Vehicle Finder，原官网仅作只读资料来源。咨询归我们自己的独立后台，不发送给原车商。

不必下载云环境 ZIP，也不必在电脑安装运行。免费云上线按 [DEPLOY_FREE.md](DEPLOY_FREE.md) 完成：

1. 登录/注册 Neon，创建 Free PostgreSQL 项目。
2. 登录/注册 Render，连接自己的 GitHub 仓库 `gavingao202608-warren/warren1`，用仓库中的 `render.yaml` 创建 Blueprint，保持 Free。
3. 把 Neon 连接串直接填进 Render 的 DATABASE_URL 私密字段。不要发给聊天，也不要提交到 GitHub。公网地址自动取得，获客实验起点自动持久保存。

部署完成，把实际公开网址发给开发助手继续核验，不要发密码或连接串。

独立站运营者使用自己获准使用的渠道带来真实买家访问，每天查看后台并跟进已同意提供联系方式的咨询。测试表单、自点链接和手写来源不计作获客。确认至少一条真实购车需求才算初步验证成功。
