# 今天零预算验证：给电脑操作者

目标：获得至少一条真实买家的、可跟进且经店方确认的购车咨询。网址打开不算成功。

## 1. 先开免费临时公网演示

安装 Node.js 24 LTS（https://nodejs.org/），解压交付包，在项目文件夹打开终端，依次执行：

```
npm ci
npm run build
npm start
```

另开终端，从 Cloudflare 官方 GitHub 发布页安装与你的系统匹配的 cloudflared：https://github.com/cloudflare/cloudflared/releases/latest 。保持校验和及系统安全检查；不要关闭证书验证。

```
cloudflared tunnel --url http://localhost:3000 --protocol http2
```

如果成功，终端会输出实际的 `https://……trycloudflare.com` 地址。不是预先分配的固定地址。若失败，不要重复盲试；保留错误信息诊断。普通电脑网络不一定有本环境限制，但无法事先保证成功。

将实际地址添加到自动生成的 `.env.local` 中，保留原来的管理员密码，另外加两行：

```
PUBLIC_BASE_URL=https://实际生成的地址.trycloudflare.com
ACQUISITION_STARTED_AT=实际开始时刻，例如2026-10-09T15:00:00Z
```

Ctrl+C 停止 npm start 后重启 npm start；保持隧道终端运行。用手机关闭 Wi-Fi，通过流量打开实际网址，进入车辆页并检查价格、联系方式入口及隐私说明。只做一次明确标为测试的咨询；这条手动测试记录不得算客户。

临时网址用于现场演示和短期直接获客，电脑必须持续开机。它不适合长期搜索收录。生产版本需要稳定托管和持久数据盘，交付包已含 Docker Compose 配置。尚未核实任何免费平台能无条件长期承载当前完整架构，不能作保证。

## 2. 发布前确定谁跟进

店方指定一人看 `/admin`，密码在本机 `.env.local`，不要在聊天里发密码。当前版本不会自动给店方发邮件或短信；必须查看后台并及时跟进。

咨询里的车型、价格、费用与实时在售状态需店方确认；不要替店方承诺最终成交价格、车况或融资结果。先获得店方使用车辆素材、品牌和渠道的授权。

## 3. 今天获取真实访问

由店方在已经有买车人群的合法现有渠道发布 3 辆代表性真实车辆：实际价格、里程、位置、车辆详情链接，每辆一个链接。选择已有网站、社媒账户或允许销售帖的本地群，不买广告、不群发陌生人私信。

示例文案结构：
“[实际年份和车型]，库存页标价 [实际 CAD 价格]，里程 [实际 km]，Scarborough。详情及向店方咨询：[真实车辆链接]。在售状态与最终费用请向店方核实。”

店方发布对应渠道参数，例如自己的 Instagram 链接用 `?utm_source=instagram&utm_campaign=first_validation`。不要伪写 google/chatgpt 来源。

观察访问、车辆咨询、同意提供联系方式的咨询，以及店方联系后确认的购车需求。最后一项至少 1 条才记为当日初步获客成功；没有线索就如实报告曝光数和问题，不宣布成功。

## 4. 搜索平台放在稳定发布后

稳定 HTTPS 地址上线后，用真实站点所有者账号验证 Google Search Console / Bing Webmaster Tools，提交 `/sitemap.xml`。ChatGPT 没有这里已经验证可用的“一键强制推荐”能力；开放抓取和有价值的真实页面不保证展示。

当前我需要你提供的不是密码，而是：你的电脑能运行上述命令、正常联网，以及店方可使用的现有发布渠道和负责跟进的人。搜索平台账号不是今天直接获客试验的先决条件。
